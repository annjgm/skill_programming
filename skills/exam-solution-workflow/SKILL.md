# 程式設計競賽試題解題與詳解產製 SOP

本 Skill 定義「全國高級中等學校商業類學生技藝競賽【程式設計職種】」各年度試題之解題、演算法剖析、邊界測試與 Markdown 詳解文件產製之標準作業程序。

## 一、 解題前準備與資源對照

在進行解題前，必須確認試題來源目錄與檔案：
- **學科試題**：`{年度}/01_學科/` 下之正式試卷 PDF 與官方答案 PDF。
- **術科正式試題**：`{年度}/02_術科/正式試題/`。
- **術科模擬試題**：`{年度}/02_術科/模擬試題/`（包含 `01_Advanced` 與 `02_Beginner`）。

## 二、 三段式解題標準模板

所有題目的 Markdown 詳解輸出必須嚴格依照以下三段式結構：

```markdown
### Problem X: [題目名稱]

#### 1. 題目簡述與規格說明
- **題目背景與任務**：簡明扼要說明題目情境與目標。
- **輸入格式**：明確列出測資結構、行數、終止條件（例如 EOF、0 或特定旗標）。
- **輸出格式**：數值格式、換行規範、浮點數小數位數。
- **測資邊界與限制**：如 $N \le 10^5$、$O(N \log N)$ 時間上限等。

#### 2. 核心觀念說明
- **演算法核心**：剖析解題的核心思想（如動態規劃、雙指標、拓撲排序、並查集等）。
- **資料結構選用**：說明選用該結構（如 `heapq`, `collections.deque`, `set`）之優勢。
- **複雜度分析**：
  - 時間複雜度：明確給出 Big-O（例如 $O(N)$）。
  - 空間複雜度：給出額外輔助空間佔用。
- **極端測資與常見陷阱**：提示邊界測資（如 $N=0$、負數取模、空集合、大數逾時、浮點數誤差）。

#### 3. 正確答案編碼簡析
```python
# 符合競賽標準且可直接執行的 Python 3 參考程式碼
import sys

def solve():
    # 邏輯實作
    pass

if __name__ == '__main__':
    solve()
```
- **代碼逐步解析**：針對上述代碼之關鍵區塊逐一拆解說明其執行原理。
```

## 三、 命題趨勢與考點深度參考庫

撰寫解析時，請依題型領域對齊以下經典技巧與模式：

### 1. 學科測驗題追蹤（Tracing）要點：
- **位元運算**：位元移位（`>>`, `<<`）、位元及（`&`）、位元或（`|`）、位元互斥或（`^`）與 XOR 交換律。
- **模運算**：Python 負數取模與除數符號一致性（如 `-7 % 3 = 2`）。
- **短路求值**：`and`、`or` 的非布林返回值特性與執行順序。
- **迴圈變數作用域**：雙重/三重迴圈中未重置變數導致的累積錯誤。
- **串列走訪修改**：在 `for x in list:` 走訪時進行 `remove()` 或 `append()` 造成的跳格副作用。

### 2. 術科實作題經典領域：
- **字串與進位制**：高精度大數轉換、任意進位制短除法、字串切片、行程長度編碼（RLE）。
- **數論與質數**：質數判定（$\sqrt{N}$ 試除）、篩法（Sieve of Eratosthenes）、質因數分解、輾轉相除法求 GCD/LCM。
- **動態規劃（DP）**：
  - 最大連續子陣列和（Kadane's Algorithm）
  - 最長嚴格遞增子序列（LIS, $O(N \log N)$）
  - 零錢兌換 / 背包問題（完全背包與 0/1 背包）
  - 二維網格最小路徑和
- **資料結構**：
  - 雙端佇列 `collections.deque`（BFS、滑動窗口）
  - 堆疊 `list`（括號匹配、中序轉後序、單調棧）
  - 優先佇列 `heapq`（Dijkstra 最短路、霍夫曼編碼樹）
  - 並查集 DSU（Kruskal 最小生成樹、連通性）
- **樹與圖論**：
  - 樹走訪重建（前序+中序重建二元樹）
  - 樹的直徑（兩次 BFS / DFS）
  - 拓撲排序與環檢驗

## 四、 產製與落盤規範

1. **檔案存放目錄**：
   - 原始 Markdown 詳解存放於：`詳解專區/{年度}/`。
2. **檔案命名**：
   - 模擬試題：`01_Advanced模擬試題詳解.md`、`02_Beginner模擬試題詳解.md`。
   - 複製至 `netlify_deploy_site/files/詳解專區/{年度}/` 時，必須在檔名前加上年度（如：`111年度01_Advanced模擬試題詳解.md`）。
3. **編碼規範**：
   - 一律採用 UTF-8 無 BOM 編碼。
   - 繁體中文與台灣程式用語（程式碼、走訪、遞迴、陣列、字典）。
